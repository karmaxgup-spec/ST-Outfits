# Outfit Tracker for SillyTavern (Fork)

A fork of the Outfit Tracker extension by **Lucanna** ([original repo](https://github.com/lannashelton/ST-Outfits)). All credit for the original extension goes to the original author.

## Changes in this fork

- **OpenAI-compatible endpoint** for auto outfit checks. Choose *OpenAI-compatible endpoint* under *Outfit check API*, then enter a Base URL, optional API key, and model.
- **Show status popups** toggle to hide the "checking" and "completed" messages. Error popups still show.

## Vibe-coded

This fork was vibe-coded with Claude from plain-language requests. It has not been extensively tested.

## Install

Copy this folder into SillyTavern's `public/scripts/extensions/third-party/` directory, or install it from this fork's repository URL via *Install Extension*. The original repo installs the original version, not this fork.
